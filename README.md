# Customer Churn & Sales Trend Analysis Dashboard

An end-to-end data intelligence project applying custom **Feature Engineering**, **Pivot Aggregations**, and **Customer Concentration Analysis (80/20 Rule)** to extract growth trends.

## 📊 Analytical Layout Architecture
This repository answers core retail operational metrics required by managerial stakeholders:
* **Date Extraction Metrics:** Transformed order timelines into clear categorical evaluations (`month`, `weekday`, `quarter`).
* **Trend Analysis:** Tracks total monthly velocity alongside strict Month-over-Month growth metrics.
* **Category Comparison:** Uses custom aggregations and pivot table layouts to breakdown categorical contribution weights.
* **High-Value Segmentation:** Isolates revenue concentration behavior to evaluate premium account behaviors.

## 📈 Executive Key Findings Summary
* **Peak Operations:** Strategic seasonal revenue maxed out during late summer windows.
* **Product Rankings:** The product category mix reveals distinct performance leads in volume distribution.
* **Customer Leverage:** The top 10% customer population demonstrates significant value concentration, proving high platform reliance.
